# User Management API

A beginner-friendly REST API built with Node.js, Express.js, MongoDB, and Mongoose. This project was created as part of my backend development learning journey.

## Features

- User registration
- Password hashing using bcrypt
- JWT-based authentication
- REST API development with Express.js
- MongoDB database integration using Mongoose
- MVC architecture
- Middleware implementation

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- bcrypt
- Nodemon



## Learning Outcomes

Through this project, I practised:

- Building REST APIs using Express.js
- Understanding MVC architecture
- Connecting MongoDB with Mongoose
- Implementing password hashing and JWT authentication
- Working with middleware

## Project Status

This is a basic backend practice project. More features and improvements may be added as I continue learning backend development.
